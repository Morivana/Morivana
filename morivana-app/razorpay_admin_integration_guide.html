1 · Payments dashboard
List all payments — captured, authorized, failed
▼

Your backend proxies GET /v1/payments to Razorpay. Never call Razorpay APIs from the React frontend directly — your key_secret would be exposed.

// Express route (server-side only)
router.get('/admin/payments', auth, async (req, res) => {
  const { from, to, count = 20 } = req.query;
  const payments = await razorpay.payments.all({
    from, to, count,
  });
  res.json(payments);
});
Status chips to show in the UI:
authorized captured failed refunded
Authorized payments auto-refund after 3 days if not captured. Flag these in your admin with a countdown timer.
2 · Capture payment
Authorized → Captured — money moves to your account
▼
Set auto-capture in Razorpay Dashboard → Account & Settings → Payment Capture. For Morivaná you almost certainly want auto-capture ON so no manual step is needed per order.

For manual capture (e.g. pre-orders or high-value review):

// POST /admin/payments/:id/capture
router.post('/admin/payments/:id/capture', auth, async (req, res) => {
  const payment = await razorpay.payments.capture(
    req.params.id,
    req.body.amount, // in paise — must equal or less than auth amount
    'INR'
  );
  await Order.findOneAndUpdate(
    { razorpayPaymentId: req.params.id },
    { status: 'paid', capturedAt: new Date() }
  );
  res.json(payment);
});

Paise, not rupees. ₹500 = 50000

3 · Issue refunds
Full or partial — tied to your returns flow
▼

Only captured payments can be refunded. Link this to your Returns tab so admin can trigger a refund directly from the order detail page.

// POST /admin/payments/:id/refund
router.post('/admin/payments/:id/refund', auth, async (req, res) => {
  const { amount, reason, notes } = req.body;
  const refund = await razorpay.payments.refund(req.params.id, {
    amount,           // partial: less than captured. Full: omit field
    speed: 'normal',  // 'normal' (5–7 days) or 'optimum' (instant, if eligible)
    notes: { reason, orderId: notes.orderId },
  });
  await Order.findOneAndUpdate(
    { razorpayPaymentId: req.params.id },
    { status: 'refunded', refundId: refund.id }
  );
  res.json(refund);
});
speed: normal

5–7 business days to customer bank

speed: optimum

Instant if bank supports, else normal fallback

Webhook refund.created fires when Razorpay processes it. Update order status from the webhook, not from the API response alone.
4 · Webhook handler
The source of truth — never poll, always listen
▼

Register https://morivanadaily.com/api/webhooks/razorpay in Razorpay Dashboard → Account & Settings → Webhooks.

// Express webhook endpoint — must use raw body parser
router.post('/webhooks/razorpay',
  express.raw({ type: 'application/json' }),
  async (req, res) => {
    const sig = req.headers['x-razorpay-signature'];
    const valid = razorpay.webhooks.validateWebhookSignature(
      req.body.toString(),
      sig,
      process.env.RAZORPAY_WEBHOOK_SECRET
    );
    if (!valid) return res.status(400).send('Invalid signature');

    const event = JSON.parse(req.body);
    switch (event.event) {
      case 'payment.authorized':
        await handleAuthorized(event.payload.payment.entity); break;
      case 'payment.captured':
        await handleCaptured(event.payload.payment.entity); break;
      case 'payment.failed':
        await handleFailed(event.payload.payment.entity); break;
      case 'refund.created':
        await handleRefund(event.payload.refund.entity); break;
      case 'order.paid':
        await markOrderPaid(event.payload.order.entity); break;
    }
    res.json({ status: 'ok' });
  }
);
Always verify the x-razorpay-signature HMAC before trusting any webhook payload. Razorpay retries failed webhooks for 24 hours — make your handlers idempotent.
Key events to subscribe:
payment.authorized payment.captured payment.failed refund.created order.paid payment.dispute.created
5 · Payment links
Send custom links for manual / B2B orders
▼

Useful for wholesale inquiries, Instagram DM orders, or COD conversions. Admin generates a link and sends via WhatsApp/email directly from the portal.

// POST /admin/payment-links
router.post('/admin/payment-links', auth, async (req, res) => {
  const { amount, customer, description, expiry } = req.body;
  const link = await razorpay.paymentLink.create({
    amount,          // in paise
    currency: 'INR',
    description,
    customer: {
      name: customer.name,
      email: customer.email,
      contact: customer.phone,
    },
    notify: { sms: true, email: true },
    reminder_enable: true,
    expire_by: expiry, // Unix timestamp
  });
  res.json({ url: link.short_url, id: link.id });
});

router.get('/admin/settlements', auth, async (req, res) => {

    from: req.query.from,

  });

});

// Fetch items in a settlement (for reconciliation)
router.get('/admin/settlements/:id/items', auth, async (req, res) => {
  const items = await razorpay.settlements.fetchReconDetails({
    year: req.query.year,
    month: req.query.month,
    day: req.query.day,
  });
  res.json(items);
});
